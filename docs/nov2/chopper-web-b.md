# nov2/chopper-web-b

Premium Illustrated screens for Review, Gym, Play, empty/error/offline sheets, and admin puzzle import. Built on the web kit from `nov2/zoro-web-kit-rc`.

Screenshots at 390 and 1280 are archived outside this repo. They are not stored under `docs/nov2/chopper-web-b/`.

Routes: `/review`, `/review/queue`, `/practice/mistakes`, `/gym`, `/play`, `/admin/import`. Gym stays under Learn. Legacy `uiKit` keeps the previous review page, play chooser, and match view.
