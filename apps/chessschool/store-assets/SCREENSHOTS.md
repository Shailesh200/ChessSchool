# Screenshot plan

No screenshots are in this folder. Capture them on a device or simulator before upload. Portrait only. The app is locked to portrait and is not an iPad layout (`supportsTablet` is false).

Suggested frames, in order, from the real app:

1. Learn — today's path and daily goal
2. A lesson, with the board and coach
3. Puzzles — daily puzzle or sprint
4. Gym — a bot game or the mode list
5. Profile — streak, name, and account

## App Store (required)

iPhone only. Apple accepts one set of the required display size, 3 to 10 screenshots.

| Display | Size (portrait) | Required |
| --- | --- | --- |
| 6.9-inch (iPhone 16 Pro Max class) | 1320 × 2868 | Yes, if this is the size the console currently requires |
| 6.7-inch (iPhone 14/15 Plus class) | 1290 × 2796 | Yes, if 6.9-inch is not the required slot |
| 6.5-inch | 1284 × 2778 | Accepted fallback on older consoles |
| iPad 13-inch / 12.9-inch | 2064 × 2752 or 2048 × 2732 | No. Do not upload. The binary is iPhone-only. |

Use the slot App Store Connect marks required. One size is enough if the console scales it. PNG or JPEG, RGB, no alpha.

## Play Store (required)

| Asset | Size | Required |
| --- | --- | --- |
| Phone screenshots | 1080 × 1920 (9:16). Min short side 320, max long side 3840. 2 to 8 images. | Yes |
| 7-inch tablet | 1200 × 1920 | No, unless Play asks because the app can be installed on tablets |
| 10-inch tablet | 1600 × 2560 | No, unless Play asks |
| Feature graphic | 1024 × 500 | Yes |
| High-res icon | 512 × 512 PNG | Yes |
| Promo video | YouTube URL | No |

Android does not have an iPhone-style "tablet unsupported" switch. If Play Console requires tablet shots, capture the same phone UI on a tablet emulator and say the layout is a centered phone column (max width 720). Do not invent a separate tablet design.
