## Result rules

`results.tsv|md|json` in `qa-sim-artifacts/` (repo root): PASS / FAIL / SKIPPED per unit with a reason. Exit 0 = all PASS, 1 = any FAIL, 2 = no FAIL but SKIPPED exist (so a skip can never look green; with a server down there are FAILs, so exit 1). The artifacts directory is the repo root `qa-sim-artifacts/` for every script, from any working directory. In the workflow, which base `eas/upload_artifact` resolves `path` from (the repo-root checkout, or `apps/mobile`) is unproven without a real run, so the step lists BOTH `qa-sim-artifacts/**/*` and `../../qa-sim-artifacts/**/*` (the same one directory; exactly one matches, the other only warns); a step before the upload fails the job if that directory is missing or has no non-dotfile (the upload glob skips dotfiles) and prints the file count. The first real run must show `Found N paths matching` with N > 0 in the upload step. Maestro runs with `--debug-output` and `--test-output-dir` (accepted by 2.0.2, see `TestCommand.kt`) both under `qa-sim-artifacts/maestro/<unit>-<flow>/`, so `takeScreenshot` images and the command JSON are uploaded (non-secret units only: the 5 non-secret units upload images; the 6 secret units get no `--test-output-dir` and every image/video under their folders is purged, text evidence only; see the v5 section); `qa-sim-scrub.py` walks that whole tree (text only: it cannot blank a password that is visible inside a PNG).
No emulator = every unit FAIL (not skipped). Server not up (did not start, or the APK check failed) = the server units FAIL (Arc's final rule), the rest still run; verdict INCOMPLETE, exit 1.

No merge-tree, no git version requirement, no reverse-apply. Any MISSING, UNLISTED, DUPLICATE-PATCH or MERGE = check 1 FAIL. The list is read with CRs stripped and a missing final newline tolerated; its sha256 is printed so the approved list can be cited.
